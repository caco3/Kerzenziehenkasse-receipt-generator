Receipt Generator API

Ein Flask-Service zur Erstellung von Belegen mit QR-Rechnungen und Druckfunktionalität.

POST /api/generate-receipt

Erstellt einen Beleg in verschiedenen Formaten (SVG, ODT, PDF oder direkter Druck).

Request Body (JSON):

{
  "value": 56.70,
  "booking_id": 1234,
  "teacher": "Frau Meier",
  "class": "Oberstufe Usterwest 3A",
  "payment_type": "bar|Twint|EZS",
  "output_type": "svg|odt|pdf|print",
  "cups_queue_name": "printer_queue_name"  // Optional, nur für Druck
}

Response:

  • SVG: Gibt SVG-Datei zurück
  • ODT: Gibt ODT-Datei zurück
  • PDF: Gibt PDF-Datei zurück
  • Print: Gibt JSON mit Druckstatus zurück: 
    {
  "status": "printed",
  "job_id": "12345",
  "printer": "printer_queue_name"
}

Beispiele:

PDF erstellen:

curl -X POST 'http://localhost:5000/api/generate-receipt' \
  -H 'Content-Type: application/json' \
  -d '{
    "value": 56.70,
    "booking_id": 1234,
    "teacher": "Frau Meier",
    "class": "Oberstufe Usterwest 3A",
    "payment_type": "bar",
    "output_type": "pdf"
  }' --output my-receipt.pdf

Beleg drucken:

curl -X POST 'http://localhost:5000/api/generate-receipt' \
  -H 'Content-Type: application/json' \
  -d '{
    "value": 56.70,
    "booking_id": 1234,
    "teacher": "Frau Meier",
    "class": "Oberstufe Usterwest 3A",
    "payment_type": "EZS",
    "output_type": "print",
    "cups_queue_name": "printer_queue_name"
  }'

GET /api/printer-status

Zeigt Status und Informationen über alle verfügbaren Drucker an.

Response:

{
  "printers": [
    {
      "name": "printer_queue_name",
      "device_uri": "hp:/usb/HP_LaserJet_Professional_P_1102w?serial=...",
      "status": "enabled|disabled|unknown",
      "ip_address": "192.168.1.100",  // null für lokale Drucker
      "type": "network|local",
      "description": "HP LaserJet Professional P 1102w"
    }
  ],
  "total_count": 1
}

Beispiel:

curl -X GET 'http://localhost:5000/api/printer-status'

Zahlungsarten

  • bar: Barzahlung
  • Twint: Twint-Zahlung
  • EZS: Einzahlungsschein (QR-Rechnung)

Ausgabeformate

  • svg: QR-Rechnung als SVG-Bild
  • odt: OpenDocument Text Vorlage
  • pdf: PDF-Dokument
  • print: Direkt an Drucker senden

Drucker-Konfiguration

Um eine Liste der verfügbaren Drucker-Queues zu erhalten:

lpstat -v

Der Bezeichner nach "Gerät für" ist der Queue-Name für cups_queue_name.
